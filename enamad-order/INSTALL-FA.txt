# فرم پرداخت اینماد

صفحهٔ مستقل PHP (بدون وردپرس) برای دریافت اطلاعات پرونده اینماد به‌صورت ۵ مرحله‌ای، پرداخت از طریق درگاه زیبال وب‌آکری، صدور فاکتور مشتری، و فاکتور جامع داخلی برای اقدام اینماد.

## دانلود ZIP

از همین برنچ گیت‌هاب فایل را دانلود کنید:

https://github.com/develop-mohammad/webakery.ir/raw/cursor/enamad-payment-form-d286/enamad-order.zip

ZIP را از حالت فشرده خارج کنید؛ پوشهٔ `enamad-order` را کامل روی هاست (کنار `license-server/`) آپلود کنید.

## لینک قابل اشتراک

بعد از آپلود پوشه روی هاست:

```
https://webakery.ir/enamad-order/
```

همین لینک را می‌توانید در تلگرام و اینستاگرام بفرستید. متای Open Graph برای پیش‌نمایش لینک تنظیم شده است.

پنل داخلی (فاکتور جامع برای اقدام اینماد):

```
https://webakery.ir/enamad-order/admin.php
```

ورود پیش‌فرض: `admin` / `change-this-password` — **حتماً روی سرور عوض کنید.**

## نصب روی هاست

1. کل پوشه `enamad-order/` را در ریشه سایت (کنار `license-server/`) آپلود کنید.
2. پوشه `data/` باید قابل نوشتن باشد (`chmod 755` کافی است اگر کاربر PHP همان مالک فایل باشد).
3. در `config.php` این موارد را در صورت نیاز تنظیم کنید:
   - `EO_ZIBAL_MERCHANT` — مرچنت زیبال (پیش‌فرض همان مرچنت license-server است)
   - `EO_PRICE_RIAL` — پیش‌پرداخت به ریال (پیش‌فرض ۲۷٬۵۰۰٬۰۰۰ = ۲٬۷۵۰٬۰۰۰ تومان)
   - `EO_TOTAL_RIAL` — هزینه کل خدمات (پیش‌فرض ۵۰٬۰۰۰٬۰۰۰ = ۵ میلیون تومان)
   - `EO_ADMIN_USER` / `EO_ADMIN_PASS`
   - `EO_NOTIFY_EMAIL` و/یا `EO_TG_BOT_TOKEN` + `EO_TG_CHAT_ID` برای اعلان سفارش پرداخت‌شده

## مراحل فرم (۵/۱ تا ۵/۵)

1. نام متقاضی، نام کسب‌وکار، موبایل به نام متقاضی
2. تلفن ثابت، ایمیل فعال، کد پستی
3. آدرس وب‌سایت، کد رهگیری پرونده مالیاتی
4. نوع دسترسی به ایمیل info یا هاست (رمز عبور اینجا گرفته نمی‌شود)
5. بازبینی و پرداخت پیش‌پرداخت ۲٬۷۵۰٬۰۰۰ تومان با زیبال (از مجموع ۵ میلیون)

بعد از پرداخت موفق، مشتری فاکتور جذاب با کد سفارش می‌بیند. تیم وب‌آکری در پنل `admin.php` فاکتور جامعی با هر ۷ مورد لازم برای اینماد می‌بیند.
