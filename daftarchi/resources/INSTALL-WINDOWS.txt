دفترچی — نصب روی ویندوز ۱۰/۱۱ ۶۴بیتی
سازنده: webakery.ir

آسان‌ترین راه
روی Daftarchi-Portable-1.0.0.exe دوبار کلیک کن. نصب لازم نیست.

یا نصب‌کننده
روی Daftarchi-Setup-1.0.0.exe دوبار کلیک کن. صبر کن تا برنامه باز شود.

یا پوشهٔ ZIP
۱. ZIP را Extract / استخراج کن (روی فایل ZIP راست‌کلیک → Extract All).
۲. داخل پوشه روی Install-Daftarchi.cmd دوبار کلیک کن.
   میانبر Daftarchi روی میزکار ساخته می‌شود و برنامه باز می‌شود.
۳. اگر خواستی بدون نصب اجرا کنی: Start-Daftarchi.cmd یا Daftarchi.exe

اگر ویندوز مانع شد
پیام «Windows protected your PC» / «ویندوز از رایانه شما محافظت کرد» طبیعی است.
۱. More info / اطلاعات بیشتر
۲. Run anyway / اجرای به‌هرحال

اگر فایل قفل است
روی فایل exe راست‌کلیک → Properties / ویژگی‌ها → پایین صفحه Unblock / رفع انسداد → OK

دادهٔ فروشگاه اینجا ذخیره می‌شود:
%APPDATA%\Daftarchi\
