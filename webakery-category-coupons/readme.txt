ساخت خودکار کد تخفیف ووکامرس برای دسته‌بندی‌های محصولات، با بازه درصدی دلخواه (مثلاً ۴۰ تا ۵۰ درصد).

== توضیحات ==

برای هر دسته‌بندی محصولات یک «کمپین تخفیف» بسازید و بازه تخفیف را تعیین کنید؛
افزونه هر بار یک کد یکتا با درصد تصادفی در همان بازه می‌سازد.

* بازه تخفیف با پله: مثلاً ۴۰ تا ۵۰ درصد با پله ۵ ← کدهای ۴۰٪، ۴۵٪ یا ۵۰٪
* هر کمپین چند دسته‌بندی (به‌همراه زیردسته‌ها) و دسته‌های مستثنا
* تخفیف درصدی، مبلغ ثابت روی هر محصول، یا مبلغ ثابت روی کل سبد
* ساخت دسته‌ای دستی (تا ۵۰۰ کد) و ساخت خودکار ساعتی/روزانه/هفتگی/ماهانه
* اعتبار (روز)، سقف مصرف هر کد و هر کاربر، حداقل/حداکثر مبلغ سبد
* «دریافت کد توسط مشتری» با شورت‌کد `[webakery_coupon campaign="1"]` و ویجت المنتور
  (اختیاری: کد فقط برای ایمیل همان مشتری معتبر باشد)
* پاک‌سازی خودکار کدهای منقضی‌شده و خروجی CSV از همه کدها

کدها همان کد تخفیف استاندارد ووکامرس هستند؛ در «ووکامرس ← بازاریابی ← کدهای تخفیف» هم قابل ویرایش‌اند.

== نصب ==

1. فایل ZIP را از «افزونه‌ها ← افزودن» بارگذاری و فعال کنید.
2. به منوی «کد تخفیف دسته‌بندی» بروید و اولین کمپین را بسازید.
3. دسته‌بندی محصول را انتخاب و بازه تخفیف را تنظیم کنید.

== شورت‌کد ==

`[webakery_coupon campaign="1" title="تخفیف ویژه" button="دریافت کد تخفیف" note="فقط تا پایان هفته"]`
