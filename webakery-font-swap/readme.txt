بهینه‌سازی فونت‌ها از یک پنل: فقط woff2، حذف preloadهای TTF/Google، font-display:swap برای IRANSansX.

== Description ==

* تشخیص فونت‌های تم و پلاگین‌ها + مسیر قطعی IRANSansX
* Preload اولویت با فونت متن (نه Font Awesome)
* بازنویسی CSS فونت محلی با font-display:swap داخل خود فایل
* حذف preloadهای مضر و Google Fonts
