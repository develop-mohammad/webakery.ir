# Design System — ورود آسان (WBL DS)

سیستم طراحی مخصوص **صفحه ورود / ثبت‌نام** محصول ورود آسان (webakery.ir).

## هدف محصول
ورود سریع و قابل‌اعتماد با:
1. شماره موبایل + OTP
2. حساب گوگل / جیمیل

لحن برند: **آرام، شفاف، مدرن، ایرانی** — نه شرکتی خشک، نه گیمی.

---

## اصول

| اصل | معنی |
|-----|------|
| Brand first | نام «ورود آسان» در ویوپورت اول دیده شود؛ تیتر از برند قوی‌تر نباشد |
| یک ترکیب | صفحه ورود یک صحنه است، نه داشبورد |
| شیشه روی اتمسفر | فرم شیشه‌ای؛ پس‌زمینه گرادیان/نور واقعی، نه سفید تخت |
| یک کار در هر مرحله | یا موبایل، یا کد — هرگز هم‌زمان |
| RTL طبیعی | فاصله‌ها، آیکون‌ها و تراز برای فارسی |
| المنتور-دوست | توکن‌ها با CSS variable؛ رنگ Global المنتور قابل اتصال |

## کامپوننت‌ها

### 1. Page Shell
اسپلیت دسکتاپ: **پنل برند با موكاپ گوشی OTP** (لنگر بصری واقعی) + فرم شیشه‌ای.
موبایل: موكاپ کوچک‌تر بالای صفحه، سپس فرم.

### 2. Glass Panel (`.wbl-box`)
ظرف تعامل ورود. اورب نوری ملایم داخل پنل.

### 3. Button Primary
پس‌زمینه accent، متن سفید، سایه رنگی، هاور lift ۱px.

### 4. Button Google
سطح شیشه‌ای روشن، بوردر ملایم، آیکون رسمی گوگل.

### 5. Field
لیبل بالا + اینپوت شیشه‌ای؛ فوکوس = بوردر accent + ring نرم.

### 6. OTP Field
همان Field با letter-spacing زیاد و تراز وسط.

### 7. Alert
شیشه کوچک؛ خطر قرمز / موفقیت سبز؛ انیمیشن shake برای خطا.

### 8. Divider «یا»
خط محو + قرص متن.

### 9. Step states
- `phone` — ورود شماره
- `code` — تأیید OTP
- `logged` — خوش‌آمد

فقط **یک** state در DOM قابل‌رؤیت (`[hidden]` محافظت‌شده).

---

## موشن (حداقل ۳ حرکت)
1. **Rise** ورود پنل (۰٫۵۵s)
2. **Step-in** تعویض مرحله
3. **Float** اورب‌های نوری پس‌زمینه پنل
4. (اختیاری) Spinner دکمه هنگام ارسال

`prefers-reduced-motion: reduce` همه را خاموش کند.

---

## دسترسی‌پذیری
- کنتراست متن روی شیشه ≥ WCAG AA روی پس‌زمینه نمونه
- فوکوس کیبورد واضح (`outline` / ring)
- لیبل مرتبط با `for` / `id` یکتا در هر نمونه ویجت
- پیام خطا با `role="alert"`
