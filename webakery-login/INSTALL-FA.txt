ورود آسان | لاگین پیامکی و جیمیل
================================

نصب
----
1) فایل ZIP را از پیشخوان وردپرس → افزونه‌ها → افزودن → بارگذاری افزونه نصب کنید
   یا پوشه webakery-login را در wp-content/plugins/ کپی کنید.
2) افزونه را فعال کنید.
3) منوی «ورود آسان» را باز کنید و تنظیمات را انجام دهید.

المنتور
-------
ویجت «ورود آسان» را از دسته «وب‌آکری» به صفحه بکشید.
عنوان را با ویجت Heading المنتور بگذارید (نمایش عنوان افزونه خاموش است).
ظاهر شیشه‌ای است؛ رنگ اکسنت، بلور و گردی گوشه از استایل ویجت تنظیم می‌شود.

شورت‌کد
-------
[webakery_login]
بدون عنوان (برای صفحه المنتور):
[webakery_login show_title="0"]
با ریدایرکت:
[webakery_login redirect="https://example.com/account/"]

ورود با موبایل (OTP)
--------------------
تب پیامک → یکی از پنل‌ها:
- ملی‌پیامک (Melipayamak): نام کاربری + رمز + اختیاری bodyId پترن خدماتی
- کاوه‌نگار: API Key + نام قالب Verify
- IPPanel / فراز: API Key + کد پترن
- قاصدک: API Key + نام قالب

متن پیامک نمونه: کد ورود شما: {code}

ورود با جیمیل
-------------
1) در Google Cloud Console یک OAuth Client از نوع Web بسازید
2) Client ID و Client Secret را در تب جیمیل وارد کنید
3) Redirect URI نمایش‌داده‌شده در تنظیمات را در کنسول گوگل ثبت کنید

نکات
----
- دوره آزمایشی ۷ روزه دارد؛ لایسنس از منوی «لایسنس افزونه‌ها»
- شماره موبایل در پروفایل کاربر قابل ویرایش است
- سازنده: webakery.ir
