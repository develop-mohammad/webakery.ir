وب‌اپلیکیشن برنامه‌ریزی روزانه با زمان‌بندی هوشمند، عادت‌های تکرارشونده و تقویم شمسی.

== Description ==

* برنامه‌ریزی هوشمند روز بر اساس اولویت و مدت کارها
* عادت‌های روزانه تکرارشونده
* تایم‌لاین فارسی با تاریخ شمسی
* ذخیره روی حساب کاربر وردپرس
* شورت‌کد `[roozam]`

سازنده: [webakery.ir](https://webakery.ir)

== Installation ==

1. ZIP را نصب و فعال کنید
2. منوی «روزم» را برای ساعات پیش‌فرض پیکربندی کنید
3. شورت‌کد `[roozam]` را در یک برگه قرار دهید
