نصب چت باکس Webakery
=====================

1. فایل webakery-chat-box.zip را نصب و فعال کنید.
2. چت باکس ← تنظیمات — ظاهر ویجت را تنظیم کنید.
3. برای اعلان به تلگرام:
   - از @BotFather یک ربات بسازید و Token را وارد کنید
   - Chat ID خود را از @userinfobot بگیرید
   - تیک «اعلان تلگرام» را بزنید و «تست تلگرام» را امتحان کنید
4. برای اعلان به واتساپ (CallMeBot):
   - به +34 644 66 92 45 پیام دهید: I allow callmebot to send me messages
   - API Key + شماره خود را وارد کنید
   - «تست واتساپ» را بزنید
5. پیام‌های مشتریان در «صندوق پیام» و همزمان در تلگرام/واتساپ شما می‌آید.

سازنده: webakery.ir
