# کلون UI صرافی ارز دیجیتال (مدل‌سازی kifpool.me)

مدل‌سازی رابط کاربری صفحه اصلی یک صرافی ارز دیجیتال فارسی/RTL، با الهام از ساختار و دیزاین
[kifpool.me](https://kifpool.me/): هیرو با فرم ثبت‌نام، جدول قیمت زنده‌نما با تب، بنتوگرید
ویژگی‌ها، بخش امنیت با موکاپ گوشی، اسلایدر نظرات کاربران، بخش دانلود اپلیکیشن، مراحل ایردراپ،
آکاردئون پرسش‌های متداول و فوتر چندستونه.

⚠️ این پروژه صرفاً یک **مدل‌سازی رابط کاربری (UI mock)** است:

- داده‌های قیمت، اعداد آماری و نظرات کاربران **نمونه (mock)** هستند و به هیچ API واقعی متصل نیستند.
- نام و برندینگ اختصاصی (کیف‌نما) برای جلوگیری از سوءاستفاده تجاری از برند اصلی تغییر کرده است.
- هیچ منطق مالی، احرازهویت یا اتصال بانکی واقعی پیاده‌سازی نشده است.

## اجرا

```bash
cd kifpool-clone
npm start
```

سپس باز کنید: [http://127.0.0.1:8766](http://127.0.0.1:8766)

## ساختار

```
kifpool-clone/
  index.html
  assets/css/style.css
  assets/js/app.js
  assets/img/logo-mark.svg
```

## امکانات تعاملی پیاده‌سازی‌شده

- تب‌های جدول قیمت (محبوب‌ترین / جدیدترین / پرسودترین / سهام) با داده‌های نمونه
- آکاردئون FAQ (دو بخش)
- اسلایدر افقی نظرات کاربران
- منوی موبایل (همبرگری)
- سوییچ تم روشن/تیره با ذخیره در `localStorage`
- نوار پیشنهاد هدیه با دکمه بستن

سازنده: [webakery.ir](https://webakery.ir)
