== Description ==

**سجست‌یاب گوگل** همان پیشنهادهایی را جمع می‌کند که با تایپ در سرچ‌باکس گوگل دیده می‌شوند.

* فاصله قبل و بعد از عبارت (مثل «کفش » و « کفش»)
* حرف‌گردانی الفبای فارسی (کفش ا … کفش ی)
* حروف انگلیسی، ارقام و پیشوندهای رایج (اختیاری)
* فقط پاسخ واقعی گوگل — کیورد ساختگی تولید نمی‌شود
* خروجی کپی، CSV و TXT

سازنده: [webakery.ir](https://webakery.ir)

== Installation ==

1. ZIP را از پیشخوان ← افزونه‌ها ← بارگذاری نصب کنید.
2. افزونه را فعال کنید.
3. منوی «سجست‌یاب گوگل» را باز کنید و عبارت پایه را استخراج کنید.
