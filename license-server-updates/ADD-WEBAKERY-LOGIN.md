# افزودن محصول ورود آسان به سرور لایسنس

شناسه محصول: `webakery-login`

در جدول/کانفیگ محصولات license-server این مورد را ثبت کنید:

| فیلد | مقدار |
|------|--------|
| product | `webakery-login` |
| name | ورود آسان \| لاگین پیامکی و جیمیل |
| price | ۲۴۹,۰۰۰ تومان |
| version | 1.0.1 |
| zip | `webakery-login.zip` (در پوشه updates) |

فایل ZIP افزونه در ریشه ریپو: `webakery-login.zip`

نمونه در `config.php`:

```php
'webakery-login' => 2490000, // ریال
```

و در `LS_UPDATES` / `LS_PLUGIN_LABELS` برچسب و لینک بسته را اضافه کنید.
