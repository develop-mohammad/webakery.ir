نصب و فعال‌سازی این افزونه، تنظیمات Perfmatters بهینه‌شده برای gainstore.ir (PageSpeed Mobile) را اعمال می‌کند.

== Installation ==

1. افزونه Perfmatters را نصب و فعال کنید.
2. این ZIP را از افزونه‌ها ← افزودن ← بارگذاری افزونه نصب کنید.
3. فعال کنید تا تنظیمات اعمال شود.
4. کش را پاک کنید و سایت را تست کنید.
