رتبهٔ کلیدواژه در گوگل و بینگ، حتی بدون رقیب، و رصد بک‌لینک رقبا از API — بدون اسکرپ HTML موتور جستجو.

== Description ==

* پروژه: سایت خود + کلیدواژه (رقبا اختیاری)
* جدول رتبه: گوگل و بینگ برای سایت و رقبا
* بک‌لینک و انکر تکست از DataForSEO
* کرول مؤدب صفحات عمومی (robots.txt و sitemap)
* رتبه بینگ با Azure Bing Search
* رتبه گوگل با SerpAPI یا DataForSEO (CSE فقط تقریبی است)

سازنده: [webakery.ir](https://webakery.ir)

== Installation ==

1. ZIP را نصب و فعال کنید
2. منوی «دیدبانی» را باز کنید
3. کلیدواژه‌ها را وارد کنید و کلید API را در تنظیمات بگذارید
