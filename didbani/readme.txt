رصد صفحات عمومی رقبا و رتبه در گوگل و بینگ از طریق API — بدون اسکرپ HTML موتور جستجو.

== Description ==

* پروژه: سایت خود + دامنهٔ رقبا + لیست کلیدواژه
* کرول مؤدب صفحات عمومی (robots.txt و sitemap)
* تطبیق کلیدواژه در عنوان، H1 و متن
* رتبه بینگ با Azure Bing Search
* رتبه گوگل با SerpAPI یا DataForSEO (CSE فقط تقریبی است)
* ماتریس کیورد × دامنه × گوگل/بینگ

سازنده: [webakery.ir](https://webakery.ir)

== Installation ==

1. ZIP را نصب و فعال کنید
2. منوی «دیدبانی» را باز کنید
3. پروژه بسازید و کلید API را در تنظیمات وارد کنید
