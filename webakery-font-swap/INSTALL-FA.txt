فونت سوییپ v1.2 — بهینه‌سازی فونت‌ها (IRANSansX)

==================================================
نصب
==================================================
1) فایل webakery-font-swap.zip را در وردپرس بارگذاری کن
   (افزونه‌ها → افزودن → بارگذاری افزونه)
2) فعال کن
3) برو به: تنظیمات → فونت سوییپ
4) این گزینه‌ها را روشن بگذار (پیشنهادی برای PageSpeed):
   - فعال‌سازی افزونه
   - حذف Google Fonts
   - حذف Preloadهای مضر
   - Preload فقط woff2
   - ترجیح فونت محلی
   - font-display: swap
   - حداکثر Preload: 2 یا 3
5) ذخیره کن → اسکن دوباره
6) کش سایت / WP Rocket را پاک کن
7) Incognito → View Source
   نباید preload با .ttf یا fonts.gstatic ببینی

==================================================
نکته برای gainstore.ir
==================================================
اگر ابزار ShetabWP برای IRANSansX می‌گوید No Swap / No Preload:
1) حتماً نسخه 1.2 را نصب کن
2) ذخیره + اسکن دوباره
3) کش Rocket را پاک کن
4) باید IRANSansX-Regular.woff2 در Preload نهایی دیده شود
5) CSS ایران‌سنس از مسیر uploads/wbfs-font-swap با font-display:swap لود شود

Roboto را با گزینه «حذف Google Fonts» قطع کن.
Font Awesome نیاز به preload ندارد (آیکون است، نه متن LCP).
