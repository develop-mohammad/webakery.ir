سجست‌یاب گوگل — نصب روی وردپرس
================================

دو فایل ZIP لازم است:

1) webakery-google-suggest.zip   ← خود ابزار سجست
2) webakery-login.zip            ← ورود با موبایل (OTP) و جیمیل

نصب
----
1. پیشخوان ← افزونه‌ها ← افزودن ← بارگذاری افزونه
   هر دو ZIP را نصب و فعال کنید.
2. تنظیمات ← پیوندهای یکتا را یک‌بار «ذخیره» کنید (برای آدرس صفحهٔ جدا).
3. پیشخوان ← سجست‌یاب گوگل ← تنظیمات
   - «فعال بودن صفحهٔ عمومی» روشن باشد
   - آدرس صفحه را وارد کنید (پیش‌فرض: sajest)
   - لینک می‌شود: https://your-site.com/sajest/
4. پیشخوان ← ورود آسان
   - پیامک (ملی‌پیامک / کاوه‌نگار / …) را وصل کنید
   - جیمیل: Client ID و Secret گوگل + Redirect URI

استفاده بازدیدکننده
-------------------
آدرس صفحه را باز می‌کند → با موبایل یا جیمیل وارد می‌شود → استخراج سجست.

پیشخوان مدیر
------------
منوی «سجست‌یاب گوگل» برای استخراج بدون صفحهٔ عمومی هم کار می‌کند.

شورت‌کد (اختیاری)
-----------------
[webakery_suggest]

نکته
----
اگر صفحه ۴۰۴ شد: پیوندهای یکتا را دوباره ذخیره کنید.
سازنده: webakery.ir
