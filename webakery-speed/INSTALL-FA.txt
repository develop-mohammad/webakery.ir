پنل سرعت یکپارچه v1.1 — WebAkery Speed

==================================================
منوها
==================================================
1) اولویت‌ها — اسکن و چک‌لیست
2) گوگل / CWV — دریافت خودکار Core Web Vitals
3) اصلاح خودکار — اعمال fix روی HTML سایت
4) فونت سوییپ — بهینه‌سازی اجباری فونت

==================================================
اتصال گوگل / CWV
==================================================
1) پنل سرعت → گوگل / CWV
2) (اختیاری) کلید PageSpeed Insights API از Google Cloud
3) دکمه «دریافت خودکار CWV از گوگل»
4) LCP / INP / CLS فیلد دیتا در اولویت‌ها ذخیره می‌شود

نکته: اتصال کامل OAuth سرچ‌کنسول جداست؛ این روش همان داده میدانی CWV را می‌گیرد.

==================================================
اصلاح خودکار
==================================================
1) اول «اسکن صفحه» را در اولویت‌ها بزن
2) برو اصلاح خودکار → «روشن کردن اصلاح‌های مرتبط»
3) کش را پاک کن
4) در View Source باید WBS_AUTOFIX=1 دیده شود

اصلاح می‌کند:
- width/height تصاویر
- lazy برای تصاویر غیر اول
- fetchpriority برای تصویر اول
- async کردن CSS آیکون

اصلاح نمی‌کند (عمداً):
- تبدیل WebP
- فشرده‌سازی فایل‌های حجیم
- تأخیر کامل JS فروشگاهی
