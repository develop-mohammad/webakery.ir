== Description ==

**سجست‌یاب گوگل** همان پیشنهادهایی را جمع می‌کند که با تایپ در سرچ‌باکس گوگل دیده می‌شوند — مناسب سئوکار و دیجیتال‌مارکتر.

* فاصله قبل و بعد از عبارت (مثل «کفش » و « کفش»)
* حرف‌گردانی الفبای فارسی (کفش ا … کفش ی)
* حروف انگلیسی، ارقام و پیشوندهای رایج (اختیاری)
* لانگ‌تیل از ادامهٔ همان سجست گوگل
* اینتنت، درخت کیورد و پیلار کلاستر
* فیلتر سوالی (چیست / چگونه / چرا)
* بریف محتوا و عنوان/متا فقط از عبارت‌های واقعی گوگل
* امتیاز رقابت نسبی (نه KD ساختگی اهرفس)
* تاریخچه گزارش و مقایسه دو عبارت پایه
* خروجی CSV اکسل، TXT و کپی
* صفحهٔ جدا روی سایت (آدرس دلخواه مثل `/sajest/`) با ورود موبایل یا جیمیل
* میزان سرچ ماهانه فقط از Google Ads Keyword Planner — بدون عدد ساختگی

سازنده: [webakery.ir](https://webakery.ir)

== Installation ==

1. ZIP سجست‌یاب و ZIP «ورود آسان» را نصب و فعال کنید.
2. پیوندهای یکتا را یک‌بار ذخیره کنید.
3. سجست‌یاب گوگل ← تنظیمات: آدرس صفحه را وارد کنید.
4. ورود آسان را برای پیامک و جیمیل تنظیم کنید.
