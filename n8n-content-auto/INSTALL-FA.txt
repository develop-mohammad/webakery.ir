اتوماسیون محتوای دسته — خارج از سایت (مثل n8n)

این کار داخل وردپرس نصب نمی‌شود. موتور روی n8n (یا ورکر پایتون) است
و فقط از بیرون، با REST، متن دسته را روی سایت می‌نویسد.


کجا اجرا می‌شود؟
---------------
۱) n8n روی سرور جدا / لپ‌تاپ / Docker — نه روی افزونهٔ سایت
۲) زمان‌بند خود n8n: هر ساعت یک بلوک
۳) سایت فقط مقصد نوشتن است (Application Password)


ورک‌فلو خودکار
-------------
گوگل‌شیت (بلوک بعدی بدون تیک)
  → کلمات کلیدی + عنوان + LSI + برند
  → پرامپت مقالهٔ سئو که نوشتید
  → تولید HTML
  → بررسی انسانی ۱ (بازنویسی)
  → بررسی انسانی ۲ (امتیاز JSON)
  → اگر تایید نشد: هیچ چیز روی سایت نوشته نمی‌شود
  → اگر تایید شد: متن دسته در وردپرس
  → تاریخ شمسی + تیک «انجام شد» در همان ردیف شیت
  → توقف؛ ساعت بعد بلوک بعدی


ستون‌های شیت (ردیف ۱ هدر)
-----------------------
A دسته
B عنوان
C کیورد اصلی
D کیورد فرعی
E برند
F انجام شد   ← چک‌باکس
G تاریخ      ← شمسی مثل 1405/06/22
H یادداشت

اگر چند ردیف کیورد زیر یک دسته باشد و ستون دسته خالی باشد،
همان بلوک حساب می‌شود.


راه‌اندازی n8n با Docker
----------------------
cd n8n-content-auto
cp .env.example .env
# SHEET_ID و AI_KEY و WP_* را پر کنید

docker compose up -d
# مرورگر: http://localhost:5678

وارد n8n شوید:
1. Variables را مطابق .env بگذارید (یا همان env داکر)
2. Credentials:
   - Google Sheets OAuth2 برای دو نود شیت
   - HTTP Basic Auth = کاربر وردپرس + Application Password
3. Import: workflows/category-seo-content.json
4. Active را روشن کنید (زمان‌بند ساعتی)

وردپرس: کاربران → نمایه → Application Passwords
طبقه‌بندی پیش‌فرض: product_cat (دسته محصول ووکامرس)


اگر n8n ندارید (همان جریان با کرون)
---------------------------------
python3 worker/run.py --env-file .env
# یک بلوک در هر اجرا

کرون سرور (خارج از سایت):
0 * * * * cd /path/n8n-content-auto && python3 worker/run.py --env-file .env

برای نوشتن شیت: فایل JSON حساب سرویس گوگل، یا Apps Script داخل apps-script/Code.gs


تست محلی بدون کلید واقعی
------------------------
python3 tests/test_flow.py
python3 worker/run.py --fixture tests/fixtures/sheet.csv --dry-run
