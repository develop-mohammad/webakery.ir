# افزودن محصول daftarchi به license-server

وضعیت: مشخصات روی ریپو ثبت شده — فایل‌های `license-server/config.php` و `config.FIXED-HOST.php` را روی هاست هم به‌روز کن.

## مشخصات محصول

| فیلد | مقدار |
|------|--------|
| شناسه | `daftarchi` |
| نام | دفترچی — حسابداری دسکتاپ |
| نسخه فعلی | **1.0.0** |
| نوع | برنامه Electron ویندوز (نه افزونه وردپرس) |
| مسیر ریپو | `daftarchi/` |
| اتصال | یک سیستم (`domain` = شناسه ماشین مثل `darchi-xxxx.pc`) |

## پلن‌ها (تومان)

| پلن | مدت | قیمت |
|-----|-----|------|
| `1m` | ۱ ماه | ۱۹۹٬۰۰۰ |
| `3m` | ۳ ماه (پیشنهادی) | ۴۹۹٬۰۰۰ |
| `12m` | ۱۲ ماه | ۱٬۴۹۰٬۰۰۰ |

پرداخت موفق همان مدت را به `expires_at` اضافه می‌کند (`create_or_extend_subscription`) و `periods_paid` را یکی زیاد می‌کند.

## تخفیف تمدید زودهنگام

اگر حداقل **۳ روز** به پایان دوره مانده باشد:

- ۱ دورهٔ قبلی → ۵٪
- ۲ → ۶٪
- ۳ → ۷٪
- ۴ → ۸٪
- ۵ به بعد → ۹٪

خرید اول (بدون لایسنس قبلی) تخفیف ندارد.

## کلاینت

دفترچی کلید را فعال می‌کند با `action=activate` و `validate`. صفحهٔ پرداخت:

`https://webakery.ir/license-server/pay/?plugin=daftarchi&plan=3m&domain=darchi-xxxx.pc`
