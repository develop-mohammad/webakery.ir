== Description ==

**کانال‌یار** مطالب وردپرس را به پست آمادهٔ تلگرام تبدیل می‌کند؛ نه فقط کپی لینک.

* ارسال خودکار نوشته / برگه / محصول به کانال
* ۱۰ قالب ایده: نکته، چک‌لیست، سؤال، اشتباه رایج، خلاصه، نقل‌قول، قبل/بعد، دعوت، باور غلط، رشته ۳ تایی
* تقویم ۷ روزه رشد از روی محتوای خودتان
* ایده روزانه زمان‌بندی‌شده
* ربات عضویت: /start /latest و جستجو
* پروکسی برای هاست ایران
* شورت‌کد `[webakery_channel]`
* دوره آزمایشی ۷ روزه + لایسنس webakery.ir

سازنده: [webakery.ir](https://webakery.ir)

== Installation ==

1. ZIP را نصب و فعال کنید.
2. کانال‌یار ← ربات و کانال: توکن @BotFather و یوزرنیم کانال.
3. ربات را ادمین کانال کنید و «ارسال تست» بزنید.
4. از «ایده از محتوا» پست بسازید و بفرستید.
