ورود و ثبت‌نام با شماره موبایل (OTP) و جیمیل — ملی‌پیامک، کاوه‌نگار، IPPanel، قاصدک.

== Description ==

* ورود با کد یک‌بارمصرف پیامکی
* ورود با حساب جیمیل (Google OAuth)
* پنل‌های ایرانی: ملی‌پیامک، کاوه‌نگار، IPPanel، قاصدک
* شورت‌کد `[webakery_login]`
* ثبت‌نام خودکار کاربر
* جایگزینی اختیاری صفحه wp-login

سازنده: [webakery.ir](https://webakery.ir)

== Installation ==

1. ZIP را نصب و فعال کنید
2. منوی «ورود آسان» را پیکربندی کنید
3. شورت‌کد را در یک صفحه قرار دهید
