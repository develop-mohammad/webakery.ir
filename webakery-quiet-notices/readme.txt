خاموش و مخفی کردن نوتیفیکیشن‌های شلوغ افزونه‌ها در پیشخوان وردپرس.
سازنده: webakery.ir

== Description ==

خیلی از افزونه‌ها پیشخوان را با بنر و اعلان پر می‌کنند. **سکوت نوتیف** آن‌ها را خاموش می‌کند.

* خاموش کردن همه / فقط افزونه‌ها
* نگه داشتن خطاهای مهم (اختیاری)
* مخفی کردن نَگ ووکامرس و آپدیت
* پشتیبان CSS برای نوتیف‌های سرسخت
* نمایش موقت با پارامتر `?wbqn_show=1`

سازنده: [webakery.ir](https://webakery.ir)

== Installation ==

1. ZIP را نصب و فعال کنید.
2. به تنظیمات ← سکوت نوتیف بروید.
