# وی‌سوت | GTA VISOTE

مرجع فارسی اخبار، شایعه، راهنما و فروشگاه محصولات مرتبط با **GTA VI**  
دامنه: [gtavistore.ir](https://gtavistore.ir)

نسخه **1.0.3** — Node.js — **بدون وردپرس و بدون PHP**

## چرا این‌جوری؟

وردپرس برای اولین سایت سنگین است: دیتابیس، قالب، افزونه، به‌روزرسانی.  
وی‌سوت یک CMS کوچک است با همان کارهای روزمره:

- نوشته (خبر / شایعه / راهنما)
- محصول (فیزیکی، دیجیتال، باندل کنسول، نسخه ویژه، کالکشن، پک)
- سفارش و سبد
- برگه، دسته، رسانه، تنظیمات و سئو

ادمین شبیه وردپرس است، شلوغی‌اش را ندارد.

## اجرا روی سیستم خودت

```bash
cd gtavisote
node server.js
```

باز کن: `http://localhost:8787/install`

تست خودکار:

```bash
npm run check
```

## هاست

هاست PHP/cPanel کافی نیست. مسیر پیشنهادی: لیارا. راهنمای خرید و زیپ: `HOST-FA.txt`

## ساختار سایت

| مسیر | چیست |
|---|---|
| `/` | خانه + شمارش معکوس لانچ |

| `/guide` | شخصیت، نقشه، خرید |
