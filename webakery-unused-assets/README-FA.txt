Webakery Unused CSS/JS — اکستنشن کروم
=====================================

نصب:
1) کروم → chrome://extensions
2) Developer mode را روشن کنید
3) Load unpacked → پوشه webakery-unused-assets را انتخاب کنید

استفاده:
1) صفحه سایت را باز کنید
2) روی آیکون Webakery کلیک کنید
3) «اسکن صفحه فعلی» را بزنید

خروجی:
- تعداد قوانین CSS بلااستفاده
- لیست سلکتورها + فایل استایل
- لیست اسکریپت‌های JS + حجم تقریبی
- کپی CSS بلااستفاده / خروجی JSON

نکته:
- استایل‌شیت‌های دامنه دیگر ممکن است به‌خاطر CORS خوانده نشوند
- تشخیص قطعی JS اجرا‌نشده به Coverage کروم نیاز دارد
