مدیریت کامل مشتریان و فروش ووکامرس، به‌همراه پرتال مستقل و مینیمال ورود حسابدار.

== Description ==

Hesabdar دو بخش را در یک افزونه ترکیب می‌کند:

= مدیریت مشتریان و سفارش‌ها (داخل پیشخوان) =

* لیست سفارش‌ها با جستجو، فیلتر و خروجی CSV/PDF
* ایجاد و ویرایش سفارش (مشابه ووکامرس) بدون ورود به بخش سفارش‌های WC
* گزارش فروش محصولات
* گزارش مالی دوره‌ای (روز/هفته/ماه/فصل/سال، تقویم جلالی)
* صدور فاکتور برای هر سفارش (مشاهده و دانلود)

= پرتال مستقل حسابدار =

* نقش اختصاصی «حسابدار» بدون هیچ دسترسی به پیشخوان وردپرس
* آدرس اختصاصی `/accountant-panel/` برای ورود
* گزارش فروش، سفارش‌ها و محصولات با خروجی CSV/XML/PDF/JPEG
* مشاهده و دانلود فاکتور کنار هر سفارش

نیازمند ووکامرس فعال. این افزونه دارای یک دوره‌ی آزمایشی رایگان است؛ برای استفاده‌ی نامحدود، لایسنس از webakery.ir لازم است.

== Installation ==

1. فایل zip افزونه را از پیشخوان وردپرس، بخش «افزونه‌ها ← افزودن ← بارگذاری» آپلود کنید (ووکامرس باید از قبل فعال باشد).
2. افزونه را فعال کنید.
3. برای دسترسی حسابدار، از منوی «پرتال حسابدار» یک کاربر بسازید یا کاربر موجود را ارتقا دهید.

== Frequently Asked Questions ==

= اگر ووکامرس نصب نباشد چه اتفاقی می‌افتد؟ =

بخش مدیریت مشتریان/سفارش‌ها نمایش داده نمی‌شود و یک اعلان در پیشخوان نشان داده می‌شود؛ بقیه‌ی افزونه بدون خطا کار می‌کند.

= آیا حسابدار به تنظیمات وردپرس دسترسی دارد؟ =

خیر، نقش حسابدار کاملاً از پیشخوان وردپرس مسدود است و فقط پرتال اختصاصی خودش را می‌بیند.
