کنترل دسترسی امن و زمان‌بندی‌شده برای ویدیوها بر اساس کاربر، نقش و دسته‌بندی.

== Description ==

Smart Video Access Control ویدیوهای YouTube، Vimeo، MP4 و iframe را فقط پس از تأیید دسترسی کاربر نمایش می‌دهد. ویدیوی محافظت‌شده دارای نقش‌های مجاز، فهرست کاربران مجاز و مسدود، و بازه زمانی مستقل است. قوانین نقش دسته‌بندی نیز زمانی اعمال می‌شوند که قانون نقش در خود ویدیو خالی باشد.

برای اینکه نشانی یک MP4 واقعاً از دسترس مستقیم خارج شود، فایل باید پشت یک لایه تحویل دارای احراز هویت یا نشانی امضاشده (مانند CDN signed URL) قرار گیرد. هیچ افزونه وردپرس نمی‌تواند URL عمومیِ یک میزبان خارجی را پس از افشای آن به بیننده مجاز، از دسترس مستقیم او حذف کند.

== Installation ==

1. پوشه `smart-video-access-control` را در `wp-content/plugins/` قرار دهید یا ZIP افزونه را از پیشخوان بارگذاری کنید.
2. افزونه را فعال کنید.
3. از منوی «کنترل ویدیو» یک «ویدیوی محافظت‌شده» بسازید، نشانی و قوانین آن را ثبت کنید.
4. در برگه، نوشته، قالب المنتور یا ابزارک کد کوتاه از `[protected_video id="123"]` استفاده کنید.

== Usage ==

* نقش Premium را در وردپرس ایجاد کنید، سپس آن را در «نقش‌های مجاز» ویدیو یا قانون دسته انتخاب کنید.
* برای عرضه بین ۱ تا ۳۰ مرداد، فیلدهای شروع و پایان را در خود ویدیو وارد کنید.
* برای کنترل بازه روزانه ۰۹:۰۰ تا ۱۸:۰۰، بازه را برای تاریخ موردنظر ثبت کنید؛ محدودیت تکرارشونده روزانه در نسخه فعلی وجود ندارد.
* بلوک گوتنبرگ `svac/protected-video` را می‌توان با ویرایشگر بلوک یا API ثبت کرد؛ shortcode با گوتنبرگ و المنتور سازگار است.

== REST API ==

هر دو مسیر به کاربر احراز هویت‌شده با قابلیت `read` نیاز دارند:

* `GET /wp-json/svac/v1/videos/{id}/access`
* `POST /wp-json/svac/v1/videos/{id}/check`

برای احراز هویت کوکی، nonce استاندارد `X-WP-Nonce` را ارسال کنید. پاسخ هرگز URL ویدیو را برنمی‌گرداند.

== Privacy ==

افزونه برای گزارش دسترسی، شناسه کاربر، شناسه ویدیو، زمان، IP و وضعیت مجاز/غیرمجاز را در جدول `{$wpdb->prefix}video_access_logs` ثبت می‌کند. قبل از استفاده، این موضوع را در سیاست حریم خصوصی سایت اعلام کنید.

== Uninstall ==

تنظیمات در حذف افزونه پاک می‌شوند و گزارش‌ها/ویدیوها برای جلوگیری از حذف ناخواسته باقی می‌مانند. برای پاک‌سازی کامل، پیش از حذف این ثابت را در `wp-config.php` اضافه کنید:

`define( 'SVAC_REMOVE_DATA', true );`
