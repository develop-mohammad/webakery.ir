# صفحه‌های تخفیف هوشمند — یادداشت لایسنس

از نسخه **1.3.0** این افزونه به‌صورت **بدون لایسنس** توزیع می‌شود:
کلاینت `WB_License`، تب لایسنس و دوره آزمایشی از پکیج حذف شده‌اند.

اگر هنوز روی سرور لایسنس ورودی `webakery-discount-pages` دارید، می‌توانید
آن را نگه دارید (برای آرشیو نسخه‌های قدیمی) یا حذف کنید؛ افزونه فعلی دیگر
به `https://webakery.ir/license-server` وصل نمی‌شود.

شناسه محصول (legacy): `webakery-discount-pages`
آخرین نسخه دارای لایسنس: `1.2.1`
نسخه فعلی بدون لایسنس: `1.3.0`
