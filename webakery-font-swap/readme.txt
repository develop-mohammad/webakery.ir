بهینه‌سازی فونت‌ها از یک پنل: فقط woff2، حذف preloadهای TTF/Google، font-display:swap.

== Description ==

* تشخیص فونت‌های تم و پلاگین‌ها
* Preload فقط فایل‌های woff2 محلی (با سقف تعداد)
* حذف preloadهای مضر (.ttf / .woff / fonts.gstatic)
* حذف Google Fonts از صف و HTML
* اعمال font-display:swap روی @font-faceهای محلی

== Installation ==

1. ZIP را نصب و فعال کنید.
2. تنظیمات ← فونت سوییپ
3. گزینه‌های پیشنهادی را روشن و ذخیره کنید.
4. اسکن دوباره + پاک کردن کش.
