نصب و فعال‌سازی این افزونه، تنظیمات Perfmatters بهینه‌شده برای kianstock.ir را اعمال می‌کند.

== Installation ==

1. ابتدا افزونه Perfmatters باید نصب و فعال باشد.
2. این ZIP را از افزونه‌ها ← افزودن ← بارگذاری افزونه نصب کنید.
3. فعال کنید تا تنظیمات اعمال شود.
4. کش را پاک کنید و سایت را تست کنید.
5. در صورت تمایل این افزونه را حذف کنید (تنظیمات Perfmatters می‌ماند).

== Notes ==

* قبل از اعمال، از تنظیمات فعلی Perfmatters بکاپ داخلی گرفته می‌شود.
* دکمه بازگردانی در نوتیس پیشخوان نمایش داده می‌شود.
