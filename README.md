# webakery.ir

محصولات و افزونه‌های وب‌آکری.

## نوبت من (Nobat Man)

افزونه وردپرس رزرو نوبت با تقویم شمسی ایرانی، پرداخت ووکامرس و نسخه پرو.

- نسخه فعلی: **1.0.5**  
- سازنده: **webakery.ir**  
- مسیر: `nobat-man/`
- ZIP: `nobat-man.zip`
- قیمت پرو: ۵۹۹,۰۰۰ تومان
- لایسنس: اتصال به `https://webakery.ir/license-server` با شناسه محصول `nobat-man`
- شورت‌کد: `[nobat_man]`

برای ثبت محصول روی سرور لایسنس، فایل `license-server-updates/ADD-NOBAT-MAN.md` را ببینید.

- نسخه: **1.0.3**
- سازنده: **webakery.ir**
- مسیر: `webakery-login/`
- ZIP: `webakery-login.zip`
- قیمت: ۲۴۹,۰۰۰ تومان
- شناسه لایسنس: `webakery-login`
- شورت‌کد: `[webakery_login]`
- ویجت المنتور: «ورود آسان»
- امکانات: UI شیشه‌ای، ویجت المنتور، OTP پیامکی، Google/Gmail OAuth، ثبت‌نام خودکار، تست پیامک، جایگزینی wp-login

## کد تخفیف دسته‌بندی (Webakery Category Coupons)

ساخت خودکار کد تخفیف ووکامرس برای دسته‌بندی‌های محصولات با بازه درصدی دلخواه (مثلاً ۴۰ تا ۵۰ درصد).

- نسخه: **1.0.0**
- سازنده: **webakery.ir**
- مسیر: `webakery-category-coupons/`
- ZIP: `webakery-category-coupons.zip`
- قیمت: ۲۹۹,۰۰۰ تومان
- شناسه لایسنس: `webakery-category-coupons`
- شورت‌کد: `[webakery_coupon campaign="1"]`
- ویجت المنتور: «کد تخفیف دسته‌بندی»
- امکانات: کمپین برای هر دسته‌بندی، درصد تصادفی در بازه با پله، ساخت دسته‌ای و خودکار (ساعتی/روزانه/هفتگی/ماهانه)، سقف مصرف و انقضا، دریافت کد توسط مشتری، خروجی CSV، پاک‌سازی کدهای منقضی

برای ثبت محصول روی سرور لایسنس، فایل `license-server-updates/ADD-WEBAKERY-CATEGORY-COUPONS.md` را ببینید.
