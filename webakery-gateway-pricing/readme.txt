== Description ==

* هر درگاهی غیر از لیست نقدی = قسطی → کارمزد درصد یا ثابت
* درگاه‌های نقدی (پیش‌فرض wc_zibal و WC_ZPal) → امکان تخفیف درصد یا ثابت
* به‌روزرسانی آنی مبلغ در صفحه تسویه
