سجست‌یاب گوگل — نصب روی وردپرس (نسخه ۱.۳.۱)
==========================================

برای سئوکار و دیجیتال‌مارکتر: استخراج Suggest واقعی گوگل +
بریف محتوا + رقابت نسبی + تاریخچه و مقایسه. عدد حجم ماهانه
ساخته نمی‌شود مگر Keyword Planner وصل باشد.

۱) ZIP را در پیشخوان ← افزونه‌ها بارگذاری و فعال کنید.

۲) شورت‌کد را در یک برگه بگذارید تا بقیه بتوانند استفاده کنند:

   [webakery_suggest]

   مسیر: برگه‌ها → افزودن برگه → شورت‌کد را بچسبانید → انتشار.
   بازدیدکننده‌ها همان صفحه را باز می‌کنند و جستجو می‌کنند.
   نام مستعار: [wbgs_suggest]

   در المنتور: ویجت Shortcode را بگذارید و [webakery_suggest] را وارد کنید.

   شورت‌کد از پیشخوان هم کپی می‌شود:
   سجست‌یاب گوگل → جعبهٔ «قرار دادن در صفحه».

۳) مهمان به‌طور پیش‌فرض می‌تواند استخراج کند
   (تنظیمات → «اجازه استفاده برای مهمان»).
   اگر لایسنس یا آزمایش تمام شده باشد، پیام قفل دیده می‌شود نه صفحهٔ خالی.

۴) بعد از استخراج:
   - XMind و تقویم محتوا و گزارش HTML (جریان کیوردچی، بدون مقاله ساختگی)
   - منبع سجست: گوگل یا یوتیوب
   - دکمه «ترند ایران»: ترند روزانه گوگل برای کشور ایران (نه حجم ماهانه)
   - نمای «دسته‌بندی»: اول دسته محصول / محصول / برند، بعد اینتنت و پیشوند/پسوند
   - فیلتر «سوالی» برای مقالات FAQ
   - «بریف محتوا» برای H1/H2/عنوان/متا (فقط عبارت واقعی گوگل)
   - «CSV اکسل» برای شیت کمپین
   - «ذخیره گزارش» برای بازگشایی همان سید
   - عبارت دوم را پر کنید تا دو سید مقایسه شوند

۵) اختیاری — صفحهٔ جدا بدون قالب سایت:
   سجست‌یاب گوگل ← تنظیمات ← اسلاگ پیش‌فرض /sajest/
   اگر این صفحه ۴۰۴ شد، تنظیمات ← پیوندهای یکتا را یک‌بار ذخیره کنید.
   سقف درخواست روزانه مهمان را اینجا بگذارید.
