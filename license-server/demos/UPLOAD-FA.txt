الان چیکار کن (دامنه اصلی)
════════════════════════════════════════════════════════

A) اگر هنوز index.php داخل license-server/demos نداری:
   همان index.php جدید را آنجا آپلود کن
   (برای رفع 403)

B) برای محیط تست که مشتری باهاش کار کند:

   1. public_html → پوشه demo بساز
   2. وردپرس را داخل demo نصب کن
      Softaculous → In Directory = demo
   3. ZIPهای دمو را روی همان وردپرس نصب کن
   4. در index.php بگذار: $LIVE_DEMO_READY = true;
