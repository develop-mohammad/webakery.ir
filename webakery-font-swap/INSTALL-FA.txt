فونت سوییپ v1.3 — حالت اجباری بهینه‌سازی فونت (IRANSansX)

==================================================
نصب
==================================================
1) فایل webakery-font-swap.zip را در وردپرس بارگذاری کن
   (افزونه‌ها → افزودن → بارگذاری افزونه)
2) فعال کن
3) برو به: تنظیمات → فونت سوییپ
4) فقط «فعال‌سازی افزونه» را روشن بگذار
   (بقیه بهینه‌سازی‌ها اجباری‌اند و تیک جداگانه ندارند)
5) حداکثر Preload: 2 یا 3
6) ذخیره کن → اسکن دوباره
7) کش سایت / WP Rocket را پاک کن
8) Incognito → View Source
   باید ببینی:
   - <!-- WBFS_FORCE_MODE=1 -->
   - <style id="wbfs-force-iransans">
   - preload فقط برای .woff2 محلی (نه .ttf و نه fonts.gstatic)

==================================================
چه چیزهایی اجباری اعمال می‌شوند؟
==================================================
- حذف Google Fonts از HTML و enqueue
- حذف preloadهای مضر (TTF/WOFF/Google/Font Awesome)
- بازنویسی CSS فونت محلی با font-display:swap
- تزریق اجباری @font-face برای IRANSansX Regular/Bold
- Preload فقط woff2 محلی (اولویت با IRANSansX متن)

==================================================
نکته برای gainstore.ir
==================================================
اگر ابزار ShetabWP برای IRANSansX می‌گوید No Swap / No Preload:
1) حتماً نسخه 1.3 را نصب کن
2) ذخیره + اسکن دوباره
3) کش Rocket را پاک کن
4) باید IRANSansX-Regular.woff2 در Preload نهایی دیده شود
5) در HTML باید wbfs-force-iransans و WBFS_FORCE_MODE=1 باشد
