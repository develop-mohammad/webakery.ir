خرید هاست و سوار کردن وی‌سوت روی gtavistore.ir
===============================================

این سایت Node.js است. هاست وردپرس / cPanel / دایرکت‌ادمین معمولی نخر.

پیشنهاد برای بار اول: لیارا  https://console.liara.ir
پلن PaaS «زمین» الان حدود ۵۵۰ هزار تومان در ماه است (RAM نیم‌گیگ). برای شروع کافی است.
دیتابیس جدا نخر؛ داده روی فایل است.

اگر لیارا نخواستی: VPS لینوکس ایران‌سرور / پارس‌پک با Node ۱۸+ و بعد INSTALL-FA.txt


الف) دامنه
----------
دامنه سایت: gtavistore.ir
اگر هنوز ثبت نشده از ایرنیک ثبت کن.
نیازی نیست الان DNS را دست بزنی؛ بعد از ساخت برنامه در لیارا رکورد می‌گیری.


ب) حساب و برنامه در لیارا
--------------------------
1. در console.liara.ir ثبت‌نام کن.
2. برنامه جدید → پلتفرم NodeJS.
3. شناسه مثلاً gtavistore.
4. پلن زمین (یا هر پلن کوچک).
5. بعد از ساخت برنامه، از منوی دیسک‌ها دو دیسک بساز (حتی ۱ گیگ):

   نام: data      ← این را بعداً به مسیر data وصل می‌کنی
   نام: uploads   ← این را به مسیر public/uploads وصل می‌کنی

بدون این دو دیسک، بعد از هر استقرار خبر و سفارش‌ها پاک می‌شود.


ج) زیپ پروژه
------------
فقط محتویات پوشه gtavisote را زیپ کن؛ کل ریپوی webakery را نه.

روی مک/لینوکس از ریشه همین پوشه:

  bash tools/pack-host.sh

فایل gtavisote-host.zip کنار پوشه ساخته می‌شود.

روی ویندوز: وارد پوشه gtavisote شو، همه فایل‌ها را انتخاب کن، Send to → Compressed folder.
پوشه data را اگر json دارد خالی بگذار (installed.lock لوکال را داخل زیپ نگذار).


د) استقرار
----------
1. در برنامه لیارا: استقرار جدید → Drag & Drop → همان zip.
2. نسخه Node را 22 بگذار.
3. پورت را 8787 بگذار (با liara.json هم‌خوان است).
4. دیسک data را به مسیر نسبی: data
   دیسک uploads را به مسیر نسبی: public/uploads
5. استقرار را بزن.
6. صبر کن تا وضعیت «در حال اجرا» شود.
7. زیردامنه رایگان شبیه gtavistore.liara.run باز می‌شود.


ه) نصب سایت
-----------
1. برو به https://همان-زیردامنه.liara.run/install
2. آدرس سایت را فعلاً همان زیردامنه بگذار (بعد از وصل دامنه، در /admin → تنظیمات عوض می‌کنی به https://gtavistore.ir).
3. کاربر و رمز ادمین قوی بساز.
4. اگر صفحه سفید یا خطا دیدی، لاگ استقرار را در لیارا باز کن.


و) دامنه gtavistore.ir
----------------------
1. در برنامه: دامنه‌ها → افزودن gtavistore.ir
2. رکوردهایی که لیارا می‌دهد (A یا CNAME) را در DNS دامنه ثبت کن
   (ایرنیک، یا DNS همان جایی که دامنه را خریدی).
3. صبر کن تا تیک‌ها سبز شود.
4. SSL را از همان صفحه دامنه فعال کن.
5. www را اگر می‌خواهی جدا اضافه کن و به دامنه اصلی redirect بده.
6. در /admin → تنظیمات، آدرس سایت را https://gtavistore.ir بگذار.


ز) بعد از بالا آمدن
-------------------
- /admin : تلفن، کارت، اینستا، قیمت واقعی
- هر استقرار دوباره zip بفرست؛ دیسک‌ها را دست نزن تا محتوا نپرد
- بکاپ: در لیارا از دیسک data فایل پشتیبان بگیر


خطاهای رایج
-----------
نصب ذخیره نمی‌شود / بعد از ری‌استارت سایت از نو نصب می‌خواهد
  → دیسک data وصل نشده.

عکس آپلودی بعد از استقرار نیست
  → دیسک uploads وصل نشده.

سایت باز نمی‌شود
  → پورت برنامه با PORT یکی نیست؛ 8787 بگذار.

هاست cPanel خریدم سایت بالا نمی‌آید
  → آن هاست PHP است. لیارا یا VPS لازم است.
