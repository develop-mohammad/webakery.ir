ساب‌دامین لازم نیست — همه روی دامنه اصلی است.

════════════════════════════════════════════════════════
گام ۱ — ساخت پوشه demo
════════════════════════════════════════════════════════

File Manager → برو به:

  domains/webakery.ir/public_html/

پوشه جدید بساز با نام دقیق:

  demo

مسیر نهایی:
  public_html/demo/

════════════════════════════════════════════════════════
گام ۲ — نصب وردپرس داخل /demo/
════════════════════════════════════════════════════════

روش آسان (Softaculous / Installatron در DirectAdmin):

1) Install WordPress
2) Directory / In Directory را بگذار:  demo
   (خالی نگذار — وگرنه روی ریشه سایت اصلی نصب می‌شود)
3) Site URL می‌شود: https://webakery.ir/demo
4) Admin user: demo
5) Password: Demo@12345
6) زبان: فارسی

روش دستی:
- وردپرس را دانلود و داخل public_html/demo استخراج کن
- دیتابیس جدید بساز
- نصب‌کننده را از https://webakery.ir/demo باز کن

════════════════════════════════════════════════════════
گام ۳ — ووکامرس + افزونه‌های دمو
════════════════════════════════════════════════════════

1) ووکامرس را نصب و فعال کن
2) از license-server/demos این ZIPها را
   در وردپرس /demo نصب کن:

   hesabdar-demo.zip
   nobat-man-demo.zip
   access-levels-demo.zip
   baget-demo.zip
   webakery-chat-box-demo.zip

════════════════════════════════════════════════════════
گام ۴ — صفحات تست
════════════════════════════════════════════════════════

- صفحه رزرو با شورت‌کد [nobat_man]
- یک محصول تست برای checkout
- چت‌باکس را روشن کن

════════════════════════════════════════════════════════
گام ۵ — فعال‌کردن دکمه‌ها در صفحه دموها
════════════════════════════════════════════════════════

فایل license-server/demos/index.php را ویرایش کن:

  $LIVE_DEMO_READY = true;

بعد صفحه را باز کن:
  https://webakery.ir/license-server/demos/
