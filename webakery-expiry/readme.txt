بچ قیمت، موجودی و تاریخ انقضا برای ووکامرس با سوییچ خودکار رزرو.

== Changelog ==

= 1.0.4 =
* نمایش تاریخ انقضا برای مشتری در صفحه محصول و لیست فروشگاه
* درصد تخفیف برای هر قیمت بچ
* مرتب‌سازی محصولات بر اساس تاریخ انقضا (فروشگاه و پیشخوان)

= 1.0.3 =
* رفع خطای جدی هنگام فعال‌سازی (کلاس تنظیمات قبل از هوک لود می‌شود)

= 1.0.2 =
* ادمین آستانه نوتیف را با + به‌دلخواه تنظیم می‌کند (مثلاً ۹۰/۳۰/۷ روز)
* ارسال ایمیل/پیامک فقط هنگام رسیدن به آستانه، یا هر روز

= 1.0.1 =
* هشدار پیشخوان برای انقضای یک‌ماهه، دوماهه و فوری
* ویجت خانه، نشان منو، نوار ادمین
* ایمیل روزانه و پیامک اختیاری (ملی‌پیامک، کاوه‌نگار، IPPanel، قاصدک)

= 1.0.0 =
* انتشار اولیه نسخه رایگان بدون لایسنس
